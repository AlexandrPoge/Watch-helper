# План реализации Watch Helper

Обновлено 25 ноября 2026 года. Цель продукта — помочь выбрать фильм или сериал самостоятельно, вдвоём или компанией.

Отмеченные задачи реализованы и прошли указанные ниже проверки. Открытые пункты требуют дальнейшей работы или данных для развёртывания.

## 1. Стабильная основа

- [x] Запуск PostgreSQL, API и frontend через `npm run dev:stack`.
- [x] Автоматическое применение миграций при старте API.
- [x] Проверки `/health` и `/api/ready`, таймаут подключения к БД.
- [x] Проверка портов конфигурации, ограничение размера JSON и частоты API-запросов.
- [x] Единообразные JSON-ошибки для некорректных запросов и ошибок middleware.

## 2. Каталог и личный выбор

- [x] Каталог фильмов и сериалов, поиск, фильтры, страницы подробностей и актёров.
- [x] Избранное и реакции на фильмы, локальный профиль вкусов.
- [x] Сохранение фильтров каталога и рекомендации из живых данных для настроенного профиля.
- [x] Случайный выбор фильма, сериала или мультфильма.
- [x] Раздел вариантов просмотра в карточке фильма.
- [x] Проверка сохранения фильма и жанра, перезагрузки и восстановления профиля в браузере.

## 3. Кинокомнаты

- [x] Создание, вход по ссылке и коду, список комнат гостя.
- [x] Присутствие участников и обновления через Socket.IO.
- [x] Голосование для пары и группы, слепые раунды, результаты и история.
- [x] Свой список из 2–6 фильмов для ведущего, поиск и добавление из избранного. В слепом режиме порядок перемешивается.
- [x] Предложения фильмов от участников и добавление предложений в список раунда ведущим.
- [x] Мобильный переход к списку после добавления предложения и браузерная проверка с двумя сессиями.
- [x] Проверки прав хоста, вместимости, приватности голосов и повторных запросов.
- [x] Восстановление сессии и подписки при переподключении.
- [x] Получение изменений комнаты через API, если WebSocket недоступен, и защита от запоздалых голосов в новый раунд.
- [x] Резервный подбор кандидатов через PoiskKino со случайной выборкой.

## 4. Источники данных

- [x] Кэширование ответов, таймауты и обработка частичной доступности каталогов.
- [x] Дедупликация с учётом типа контента и ошибка при отказе всех источников поиска.

## 6. Развёртывание и эксплуатация

## Подтверждённые проверки

Добавлены регрессионные проверки JSON-ошибок, числовых параметров, безопасных ID каталогов и отказов sharing/clipboard. Ранее проверены Docker-сборки, локальный HTTPS-сценарий и восстановление архива. Проверены пустой поиск и ошибка карточки. Полный серверный запуск на публичном домене требует отдельного хостинга API и БД.
