# Watch Helper

Веб-приложение для выбора фильмов для себя, пары или компании.

## Архитектура

Проект использует feature-oriented структуру:

- `src/app` — точка входа, маршрутизация и глобальные провайдеры.
- `src/pages` — экранные композиции приложения.
- `src/features` — самостоятельные пользовательские возможности.
- `src/entities` — доменные модели и переиспользуемые доменные компоненты.
- `src/shared` — UI-kit, утилиты и общие типы без бизнес-логики.
- `src/lib` — внешние интеграции и инфраструктурные клиенты.

Каждый модуль должен иметь одну ответственность. Файлы ограничиваются 150 строками.
